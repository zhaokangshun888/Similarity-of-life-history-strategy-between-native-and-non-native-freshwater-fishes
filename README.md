# Similarity-of-life-history-strategy-between-native-and-non-native-freshwater-fishes
Life-history strategies reflect how fishes adapt to specific environments and play a critical role throughout the invasion process, leading to their application to understand large-scale patterns and drivers of freshwater fish invasions. Here, we compiled ecological traits for 14,679 freshwater fish species across 3,118 river basins worldwide to classify life-history strategies of native and non-native fishes and attempt to explain large-scale distributional patterns in diverse environments.

#Overview
The main branch includes the core code of this study, which is Hierarchical Modelling of Species Communities (HMSC) and generalized linear mixed models (GLMMs) for life-history strategy composition and similarity at the basin level seperately. Then, we also included the code of Trait data imputation and Classification to life-history strategies in another two branches. You can use this code and attached data to repeat the results.
